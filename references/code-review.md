## 保留的研究边界

`start` 之后从空仓开始，并在该窗口内重新预热历史和流动性条件；仅交易池状态承接历史。
缺失未来收益不改变组别，但组均值仍仅使用可观测收益，因此不替代退市资产的真实结算建模。
资金费仍按 bar 聚合，未模拟 bar 内精确持仓时刻、标记价格现金流、订单簿、保证金和强平。

## 第二轮审查

基于 `0fcb72ed80b1d5b33fc711d6ee0ccde15b34318e` 继续检查边界情况。
本轮先编写回归用例，修复前复现 13 个失败用例，涉及以下 8 类问题：

| 优先级 | 问题与复现 | 修复 |
| --- | --- | --- |
| P1 | 交易池文件为空，或仅含结束日期之后的状态时，空表被当成未提供文件，导致所有资产可交易 | 通过保留的表结构区分未提供文件与空状态表；空状态表保持所有资产不可交易，并提供相应提示 |
| P2 | `ceil(百分位排名 × 组数)` 有浮点边界误差；25 个资产分 25 组时，第 7、14 名被误分组 | 使用整数值的排名和分子分母计算组别，覆盖整除及非整除情况 |
| P2 | BTC 缺失中间 bar 时，`pct_change(fill_method=None).fillna(0)` 丢失缺口两端涨跌 | 用最后已知收盘价估值，下次报价计入全部累计变动；提示缺失数量和起始估值约定 |
| P2 | pandas 2+ 的单一格式推断拒绝同列中合法但小数秒精度不同的 ISO 时间 | pandas 2+ 显式使用混合格式解析；保留 pandas 1.5 支持及纳秒精度 |
| P2 | 数字 epoch 时间被默认当作纳秒，秒或毫秒数据可能被解释成 1970 年 | 拒绝没有显式单位转换的数值时间；数据契约给出毫秒转换示例 |
| P2 | 先删除无效因子值再检查键唯一性，掩盖同一时刻/资产存在重复记录 | 先检查规范化后的键，再过滤非有限或无效因子值 |
| P2 | 复用已有输出目录可能留下旧汇总、旧周期和新的部分结果 | 写入前拒绝非空输出目录；CLI 重复运行集成测试确认旧汇总保持原样 |
| P2 | 默认输出位置依赖源码文件位置，安装运行时可能写入 Python 库目录并遇到权限错误 | 默认输出改为当前工作目录下的 `output/`；CLI 统一捕获文件系统错误 |

额外使用独立的合约数量与现金账本，对有隔夜价差、交易费用、资金费和不同再平衡周期的模拟
进行逐期净值核对；三组核对均通过，未在这些场景中发现组合净值递推偏差。
本轮测试总数为 106 项，并继续验证 pandas 1.5.3、2.2.2、3.1.0 三组依赖。
第一轮性能数字仅记录当时版本；本轮修复了分组边界语义，不将该数字当作新版本的重新测量。
